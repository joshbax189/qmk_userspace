* OLED Key Menu

A menu for OLED displays that exposes keycodes without needing to add them to a layer.

** Installation

1. import module
   - check out submodule to qmk_userspace/modules
   - add joshbax189/oled_key_menu to keymap.json
2. define a layer for menu keys, bind those keys
   - example
3. in oled handler: add render function when layer is active
   - example
